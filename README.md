# ult with knife ($KULT)

Source for https://ultwithknife.com, a plain static site (no build step) deployed by Netlify from the `main` branch.

- `index.html` - homepage
- `lab/` - the KULT Lab (Memes, Colt Says, Knife Catch, Knife Throw, Become Colt)
- `memes/files/` - downloadable GIFs and memes plus their previews
- `img/`, `vendor/` - artwork and on-device libraries
